# Agentic Roadmap

An opinionated roadmap for agentic engineering.

Published at [Hrytsenko - Agentic Roadmap](https://hrytsenko.github.io/agentic-roadmap/).

## Develop

```sh
npm install
npm run dev      # http://localhost:4321/agentic-roadmap/
npm run build    # output in dist/
```

Pushing to `main` deploys the site.
