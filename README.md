# Agentic Roadmap

An opinionated roadmap for agentic engineering.

Published at [Agentic Roadmap](https://hrytsenko.github.io/agentic-roadmap/).

## Develop

```sh
npm install
npm run dev      # run at http://localhost:4321/agentic-roadmap/
lychee .         # check links
vale .           # check prose
```

Pushing to `main` deploys the site, checks prose with [Vale](https://vale.sh/), and checks links with [lychee](https://lychee.cli.rs/), which also runs weekly.
