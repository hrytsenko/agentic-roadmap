Practices for efficient and reliable work with LLMs and agents:

- **[Engineering](engineering/):** Use agents to increase productivity, from personal assistance to bounded delegation.
- **[Evaluation](evaluation/):** Use evaluations to ensure quality, from prompt outputs to agent behaviors.

Practices apply across all areas and are iterative. Each practice progresses through three levels. Each level has its own outcomes and extends and enhances the one before it.
