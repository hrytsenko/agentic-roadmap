Use coding agents to increase productivity, standardize workflows, and delegate tasks.

## Personal productivity

Use coding agents as interactive development assistants. Provide relevant context, write focused prompts, and iterate on proposed changes. Review and correct agent-generated work through human-in-the-loop control, starting with small, reversible tasks. Use instruction files to encode project conventions.

Key capabilities:

- Use coding agents to create, update, test, and review code.
- Write clear and focused prompts with relevant context.
- Use human-in-the-loop control to review and steer agent changes.
- Use instruction files to encode project conventions.

## Reusable workflows

Establish explicit, repeatable workflows for coding agents. Use commands and skills to share reusable workflows across the team, and hooks to control agent actions. Apply verification gates and regression checks to validate agent-generated changes before they are accepted or merged.

Key capabilities:

- Share rules, commands, skills, and hooks across the team.
- Use packages and plugins to distribute skills and MCP servers.
- Apply verification gates and regression checks.
- Integrate agents into gated CI/CD workflows.

## Bounded tasks

Delegate engineering work to autonomous coding agents using clear instructions and task definitions. Decompose larger goals into bounded, verifiable tasks with defined outcomes, constraints, and acceptance criteria. Extend agents' capabilities with specialized skills and external tools.

Key capabilities:

- Write clear and focused agent instructions and tasks.
- Break work into bounded and verifiable tasks.
- Control agent autonomy and blast radius.
- Use specification-driven development to drive agent work at scale.
- Use autonomous coding agents to implement and review changes.
- Use scorers to triage changes for human review.

:::note[Trade-off]
The trade-off is cost. As coding-agent usage becomes more sophisticated, engineers may need higher-tier subscriptions to support larger contexts and more demanding workflows. Integrating agents into CI/CD introduces usage-based costs, while autonomous agents require dedicated budgets. Further delegation of increasingly complex tasks can drive costs substantially higher, making them difficult to compare directly with developer subscription costs.
:::
