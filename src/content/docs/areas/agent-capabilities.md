Develop and share reusable agent capabilities.

## Topics

### Agent skills

Develop reusable workflows.

- Descriptions to trigger skills for relevant tasks.
- Instructions to encode procedures and domain knowledge.
- Progressive disclosure to load resources only when needed.
- Scripts to run deterministic steps and save context.

### MCP servers

Expose external tools and data.

- Tools and resources to expose actions and data.
- Tool descriptions and schemas to guide selection and validate arguments.
- Local and remote servers to reach environments and business systems.
- Authorization to secure machine-to-machine and user-delegated access.

### Infrastructure

Share and govern capabilities.

- Marketplaces and plugins to distribute skills and servers.
- Gateways to centralize access, policy, and audit for MCP servers.
- Scanners to vet skills and servers against supply-chain risks.

## Exercises

- Build an agent skill and distribute it as a plugin.
- Build an MCP server and connect it to an agent through a gateway.
