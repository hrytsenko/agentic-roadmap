# Agent instructions

The roadmap has two kinds of skills, described independently, with each skill in one place only:

- Mainline skills are composable: each one adds a new area rather than deepening the previous one.
- Crosscutting skills are iterative: each level extends and enhances the one before it. Only crosscutting skills have levels.

The page structure is still evolving, so take it from the existing pages rather than treating it as fixed.

For consistency, vendor resources lead with the vendor name, followed by the latest API, SDK, or coding agent to look for, such as "Anthropic Messages API" or "OpenAI Agents SDK". Each links to its guide or overview page.
