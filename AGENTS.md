# Agent instructions

The roadmap has areas and practices. They are orthogonal: each focuses on different things, so every topic is described in one place only, keeping duplication to a minimum.

- Areas are self-sufficient and composable: each one covers its own scope rather than deepening another.
- Practices are iterative and apply across all areas: each level extends and enhances the one before it. Only practices have levels.

For consistency, vendor resources lead with the vendor name, followed by the latest API, SDK, or coding agent to look for, such as "Anthropic Messages API" or "OpenAI Agents SDK". Each links to its guide or overview page.
