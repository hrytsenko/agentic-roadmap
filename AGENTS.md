# Agent instructions

The roadmap has areas, practices, and a route through them. Areas and practices are orthogonal, so every topic is described in one place only.

- Areas are self-sufficient and composable: each one covers its own scope rather than deepening another.
- Practices are iterative and apply across all areas: each level extends and enhances the one before it. Only practices have levels.
- The route has cumulative milestones, each covering one area and the matching level of each practice. It links to them without describing topics, so every topic and capability they contain is required.

Vendor resources lead with the vendor name, followed by the latest API, SDK, or coding agent, such as "Anthropic Messages API" or "OpenAI Agents SDK". Each links to its guide or overview page.
